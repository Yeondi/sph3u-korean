# English Speaking Lab

기존 GitHub Pages 프로젝트에 추가한 빌드 없는 학습 도구입니다. 루트의 `index.html`에서 ‘기타 학습 도구’ 카드로 이동합니다. 기존 학습 페이지는 수정하지 않았습니다.

## 제공 범위

- 1장 문장의 기본 구조, 2장 동사별 문장 구조, 3장 시제와 상.
- 각 장: A 개념 → B 구조 분석 → C 조립 4문제 → D 변형 4문제 → E 즉답 4문제 → F 복습.
- 총 36개 기본 문제 + 36개 별도 상황의 전이 복습 문제.
- 4~10장은 준비 중으로 표시하며 학습·완료 기능을 제공하지 않습니다. 전체 10장을 완성한 버전이 아닙니다.
- TTS, 지원 브라우저의 음성 받아쓰기, 무제한/15/10/5초 연습, 자기평가 및 간격 복습.
- 자동 문법 채점·발음 평가·실시간 AI 대화 기능은 없습니다.
- 진도율은 공개된 3장 기준이며, 12문제를 비교하고 자기평가한 뒤 각 장을 수동 완료할 수 있습니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 진입점, 문서 구조 |
| `styles.css` | 회로 페이지와 맞춘 색상·반응형 레이아웃 |
| `content.js` | 챕터 설명·비교 예문·성분 분석·문제 데이터 |

| `verify.cjs` | Node 내장 기능만 사용하는 콘텐츠·동작 로직 테스트 |
| `../index.html` | 기타 학습 도구 영역에 카드 1개 추가 |

## 저장과 복습

`english-speaking-lab-v1` localStorage 키만 사용합니다. 다른 페이지의 키를 읽거나 변경하지 않습니다. 답안 입력은 최대 4,000자까지 저장하며, 다시 열면 입력만 복원하고 모범 답안은 숨깁니다. 기기·브라우저 간 동기화는 없습니다.

- 어려운 문제 저장: 즉시 복습 대상.
- 다시 연습: 10분 후, 간격 단계 초기화.
- 헷갈림: 1일 후, 간격 단계 초기화.
- 저장된 문제에 ‘스스로 가능’: 1 → 3 → 7 → 14일 간격. 이후에는 14일 유지.
- 저장하지 않은 문제에 ‘스스로 가능’: 학습 기록만 저장.
- 복습 목록 제거는 해당 복습 일정만 지우고 입력·학습 기록은 보존합니다.
- 새 상황 복습과 원래 문제는 같은 구조의 복습 일정 하나를 공유합니다.

음성 입력은 사용자가 버튼을 누를 때만 시작합니다. 브라우저 업체의 서비스 사용 여부와 마이크 권한에 영향을 받습니다. 사이트 자체는 백엔드·유료 API·외부 JavaScript 라이브러리 없이 동작합니다. 음성 입력을 쓰지 않아도 모든 문제를 풀 수 있습니다.

## 검증

프로젝트 루트에서:

```sh
node --check english-speaking/content.js
node --check english-speaking/app.js
node english-speaking/verify.cjs
git diff --check
```

2026-10-20: 위 검사 통과. 테스트에서 확인한 항목:

- 3개 챕터, 고유 문제 36개, 새 상황 36개, 필수 설명과 모범 답안 누락 없음.
- 빈 입력·공백만 있는 입력의 모범 답안 공개 차단.
- 직접 말하기 체크 후 답안 비교 가능.
- 모범 답안·전이 복습 답안 표시, 자기평가 기록 및 복습 일정 변경.
- 저장한 입력 복원, 답안은 숨긴 상태로 재시작.
- 기존 회로 키 보존, 잘못된 JSON·차단된 저장소에서도 앱 실행.
- 12문제 자기평가 전 완료 방지, 완료 후 진도 반영.
- 가상 시계로 5초 타이머 종료·탐색 시 정리, 시간 만료 시 답안 미공개.
- 음성 미지원 안내, 입력 HTML 이스케이프, 상대 자산 경로·메인 링크.

**검증 한계:** 테스트는 작은 DOM 대역을 사용한 애플리케이션 로직 검사입니다. 실제 브라우저 렌더링 검사와 같지 않습니다. 이 환경의 로컬 HTTP 접속은 `EACCES`로 차단되었고 브라우저 미리보기도 연결 시간 초과가 발생했습니다. 따라서 실제 PC·모바일 레이아웃, 실제 TTS 음성·마이크 받아쓰기, GitHub Pages 배포 응답은 미확인입니다.

## GitHub 반영

저장소 루트에서 변경 내용을 검토한 뒤, 평소 사용하던 GitHub Desktop 또는 Git으로 `index.html`과 `english-speaking/`을 커밋·푸시합니다. 이 작업에서는 커밋·푸시·배포를 실행하지 않았습니다. 기존 GitHub Pages 설정을 바꿀 필요는 없습니다.

```sh
git add index.html english-speaking/
git commit -m "Add English Speaking Lab foundation course"
git push
```

배포 후 경로: `https://yeondi.github.io/sph3u-korean/english-speaking/`

실제 브라우저 확인 순서:

1. 메인 ‘기타 학습 도구’ 카드로 진입하고 4~10장이 준비 중인지 확인.
2. 1장 조립 문제에서 빈 입력으로 비교 버튼을 눌러 차단 확인, 답을 입력한 뒤 비교.
3. ‘다시 연습’을 누른 뒤 복습 목록의 전체 필터에서 새 상황 확인.
4. 새로고침 후 내 입력은 남고 모범 답안은 숨겨지는지 확인.
5. 즉답 문제에서 5초 타이머 종료 후에도 답안이 자동으로 나오지 않는지 확인.
6. TTS 영어 예문 듣기, 지원 브라우저에서 마이크 허용/거부·받아쓰기 결과를 확인.
7. 375px 모바일 폭에서 페이지 가로 넘침 없이 탐색·입력·비교가 가능한지 확인. 비교 표 자체는 가로 스크롤을 허용합니다.
8. 기존 회로 페이지의 완료 기록이 유지되는지 확인.

준비된 장만 `content.js`의 `chapters`에 추가하고 해당 `roadmap` 항목을 제거하세요. 새로운 장도 최소 12개 문제와 별도 전이 상황을 작성하고 검토합니다. 현재 렌더러는 공개 3장에 맞춘 문구·마지막 장 탐색·progress 최대값을 사용하므로, 장을 추가할 때 `index.html`, `app.js`, 메인 카드 및 테스트의 공개 수와 탐색 조건도 갱신해야 합니다. 기존 문제 ID는 저장된 복습과 연결되므로 변경하거나 재사용하지 마세요.
